# 🤖 Universal Helper Bot - Многофункциональный Telegram Бот

Мощный Telegram бот с реферальной системой для вирусного роста аудитории!

## 🌟 Основные возможности

### 📥 Скачивание контента
- **YouTube** - видео и аудио в любом качестве
- **TikTok** - видео без водяных знаков
- **Instagram** - посты, stories, reels
- **Twitter/X** - видео и GIF
- **Facebook** - видео
- **Spotify** - превью треков
- **SoundCloud** - музыка

### 🎁 Реферальная система
- Уникальная реферальная ссылка для каждого пользователя
- Статистика приглашенных друзей
- Лидерборд топ-рефералов
- Бонусы и премиум функции за рефералов

### 🛠 Полезные инструменты
- 📝 Конвертер файлов (PDF, Word, изображения)
- 🌐 Переводчик с автоопределением языка
- 📊 Генератор QR-кодов
- 🔗 Сокращение ссылок
- 🎨 Обработка изображений (сжатие, resize)
- 💱 Конвертер валют
- 🌤 Погода

## 🚀 Быстрый старт

### Требования
- Python 3.9+
- PostgreSQL (или SQLite для тестирования)
- VDS/VPS сервер

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/wolfik777/Xcsa.git
cd Xcsa

# Устанавливаем зависимости
pip install -r requirements.txt

# Настраиваем переменные окружения
cp .env.example .env
# Отредактируйте .env файл

# Запускаем бота
python main.py
```

### Docker развертывание

```bash
# Собираем образ
docker-compose build

# Запускаем
docker-compose up -d
```

## ⚙️ Конфигурация

Создайте файл `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_id
DATABASE_URL=postgresql://user:password@localhost/botdb
REDIS_URL=redis://localhost:6379
```
